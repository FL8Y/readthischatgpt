## Shared question bank (ambitious, release-time idea)
Goal: questions made once are reused by everyone, so nobody wastes AI effort remaking them.

Owner's first idea: a server where other users' question-making uses the owner's API and saves to the owner's server.
Why not exactly that: other users would spend the owner's free-key limits, a stored key can be extracted and abused, user-submitted AI questions are unreviewed and would spread errors, and a real server means hosting, accounts and upkeep.

Suggested stages:
1. Free download of a reviewed shared bank: publish the bank as a plain file on GitHub; the app fetches updates when online. No server, no cost, no key to protect. Owner publishes after review.
2. Users generate with their own free keys or copy-paste (Prompt Maker). They never use the owner's key.
3. Optional "submit a question": a reviewer (owner or a nurse) approves before it joins the shared file.
4. A real server only if there are enough users that stages 1-3 are not enough.

Other deferred items already in the plan: refine flow for generated items, AI results analysis, Explain-It, "Beat your best" challenge, growth waves to 3,000+ questions, nurse review of the bank.
