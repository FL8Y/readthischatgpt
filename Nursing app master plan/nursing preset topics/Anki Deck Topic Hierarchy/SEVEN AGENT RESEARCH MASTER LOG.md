## Required Agent Deliverables
Each agent must create and continuously update, within its own assigned subject folder:
1. `RESEARCH LOG.md` — detailed checklist of every topic, sources checked, files created/updated, verification status, current progress, blockers, and next actions.
2. Topic-specific research files in the relevant topic folders, not all dumped into the subject root.
3. `OBSIDIAN MIND MAP.md` — a Markdown heading/bullet mind map compatible with Obsidian graph linking; use internal wiki-links where practical.
4. A clear status section in its log showing completed / total topics and an evidence-based percentage. Do not claim completion without checking every descendant folder.

## Update Protocol
- Before each work cycle, reread this master log and the agent's own `RESEARCH LOG.md`.
- After each meaningful action, update the agent's own log immediately: what was inspected, what was researched, files/links changed, sources verified, remaining tasks, and the next action.
- Before stopping, inspect the assigned subtree again, reconcile the log against actual files, verify links and references, and update status.
- Agents must not overwrite another agent's files or edit sibling subject folders.
- Research must use current authoritative sources where relevant, distinguish Philippine guidance from international guidance, and never fabricate sources or facts.
- Agents are persistent-loop instructions for the agent session; do not claim background execution or autonomous continuation after the session ends unless the platform actually supports it.
