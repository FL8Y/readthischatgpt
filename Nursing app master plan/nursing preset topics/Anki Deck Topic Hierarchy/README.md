# Anki Deck Topic Hierarchy

This directory reproduces the seven-subject hierarchy provided for the Anki deck `PNLE TOP 1 (By Vinz)`.

Each subject and nested topic is represented by a real Git directory. Folder names have been normalized for consistent browsing, while topic labels are retained. Empty topic folders contain a `.gitkeep` marker because Git does not track empty directories.

This is a topic/folder scaffold only. It does not claim that question content has been imported into these folders or that each topic is fully covered by the source deck.

Main subjects:
1. Community Health Nursing
2. Fundamentals
3. Medical-Surgical Nursing
4. OB Nursing
5. PALMER
6. Pediatric Nursing
7. Psychiatric Nursing

Total nested topic directories: 637.
