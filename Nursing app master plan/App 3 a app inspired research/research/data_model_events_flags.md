# Gizmo (Android/iOS, Expo/Hermes) - Data Model, Events, Flags, Errors, i18n Addendum

Sources: Hermes string table (`strings_all.txt`, 234k lines) and `x/assets/app.config`.
Labels: **OBSERVED** = string literally present; **INFERRED** = reasoned from names/neighbours.
Caveat: a Hermes string table is a deduplicated, unordered pool. It shows names, not which schema owns which field, so field-to-entity mapping is INFERRED unless noted. No secrets reproduced (keys, DSNs, OneSignal/Facebook/Snap IDs, EAS project ID are redacted).
