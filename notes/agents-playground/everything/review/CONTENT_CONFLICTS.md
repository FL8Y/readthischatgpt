## Entry format for any newly found conflict

Record all of the following before resolving anything:

1. A stable ID and topic.
2. Exact source paths, headings/table rows, printed page and source wording for both claims.
3. Whether the disagreement is a transcription issue, textbook/source disagreement, difference in population/context, a time-sensitive change, or a true contradiction.
4. Authoritative primary evidence and its publication/effective date, with a link.
5. Disposition: preserve both with context, correct a transcription only with image evidence, or amend a derivative while leaving exact-copy notes untouched.
6. Reviewer identity/qualification and review date, if a qualified professional reviewed it. Never fill this with an AI-generated sign-off.
