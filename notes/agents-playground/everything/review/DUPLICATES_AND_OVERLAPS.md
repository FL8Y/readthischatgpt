# Duplicates and Overlaps Review

No duplicate or near-duplicate conclusions have been verified yet. Similar subject labels or overlapping page ranges are not proof of duplication.

## Required comparison method

For each suspected group, compare source content and hashes. Classify the group as one of:

- Exact duplicate
- Near-duplicate / revised version
- Complementary notes
- Overlapping page coverage
- Continuation
- Conflicting claims
- Uncertain / needs review

Do not remove any source or copy as part of this review. Record the source paths and the evidence behind each classification.
