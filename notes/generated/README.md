# Generated Study Notes

This folder stores actual notes produced from user-supplied textbook images. It is separate from prompts, templates, research logs, and project status files.

## Naming and organization
Create descriptive Markdown files organized by subject, chapter, and topic. Prefer one file per coherent chapter or topic; include printed page ranges when known. Continue the existing matching file when appropriate and never overwrite unrelated work.

## Required workflow
Inspect each supplied page, draft notes, save the Markdown file here, re-fetch the saved file, compare coverage against the image, then update the page tracker. Mark unclear content explicitly and separate source notes from added explanations.

A folder or template is not evidence that notes have been generated. Only actual note files containing verified study content count as output.
